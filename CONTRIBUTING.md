# Contributing

Thank you for helping improve `amine-validator`.

## Development

1. Install dependencies with `npm ci`.
2. Run `npm run typecheck`, `npm run lint`, and `npm test`.
3. Run `npm run test:coverage` to review test coverage.
4. Run `npm run build` to confirm the package compiles successfully.

## Code style

- Use TypeScript and prefer small, reusable modules.
- Keep validator functions pure and deterministic.
- Add tests for every new rule or behavior.

## Pull requests

Please keep pull requests focused, descriptive, and backed by tests.
